How to interpret this – and its limits

  • Levels are thresholds on the number of mapped OpenStreetMap features in a sector (High ≥ {{ thresholds.high }}, Medium {{ thresholds.medium }}–{{ thresholds.high_minus_one }}, Low below {{ thresholds.medium }}), checked against the code in business_intelligence/analysis.py.
  • Features include buildings and road segments. In a densely mapped city almost every sector reaches "High", so the heatmap separates built-up areas from sparse ones better than it ranks busy streets.
  • The heatmap does not count people. Well-mapped areas can look busier than they are, and poorly mapped areas quieter.
  • The website footer's "Crowd Score" ({{ s.heatmap.website_crowd_score }}) is the number of features returned, capped at 100. It is not a measure of people.
